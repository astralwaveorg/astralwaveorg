{% quot icon:hashtag 关于本站 %}

这是我的个人博客，用来记录技术学习、踩坑总结和生活思考。

不是技术大牛，只是个喜欢折腾的人。从 2019 年开始写代码，到后来接触 AI，一路上踩过的坑比吃过的饭还多。

**为什么写博客？**

- 好记性不如烂笔头
- 希望能帮到同样在摸索的人
- 倒逼自己总结和思考

本站没有任何推广和打赏链接，所有的内容都是免费分享的。如果您觉得有用，欢迎在文章下面留言互动，或者去 GitHub 点个 star。

**关于隐私**

- 不会在博客中暴露任何敏感信息
- 技术分享中涉及的 IP、密码等都会脱敏
- 如果发现任何泄露，请及时告知，我会立即处理
