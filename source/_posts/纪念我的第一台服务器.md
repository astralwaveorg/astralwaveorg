# 纪念我的第一台服务器

终于有了自己的服务器！

虽然是学生机，月付几十块的那种，但还是激动得不行。装了 Ubuntu，配了 SSH，终于可以随时随地折腾了。

主要干了几件事：
1. 安装了 nginx
2. 装了 Python 3.7
3. 跑起了我的第一个 Web 服务（Flask）

```python
from flask import Flask
app = Flask(__name__)

@app.route('/')
def hello():
    return 'Hello World!'
```

访问自己域名的那一刻，满足感拉满。

接下来想试试 Docker，听他们说很好用...
