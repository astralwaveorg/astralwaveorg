# 第一个爬虫程序

今天跟着教程写了一个爬虫，爬了一个小说网站。

```python
import requests
from bs4 import BeautifulSoup

url = "https://example.com"
response = requests.get(url)
soup = BeautifulSoup(response.text, 'html.parser')

titles = soup.find_all('a', class_='title')
for t in titles:
    print(t.get_text())
```
