# 探索 OpenAI o1 模型

试了传说中的 o1。

## 区别

- GPT-4: 快，但需要 prompt 引导思维过程
- o1: 内置思维链，自己会推理

## 测试

```
问：一个数组，除了一个元素外其他都出现了两次，找出那个元素

答：[1, 2, 3, 1, 2]
    
思路：用异或...
```

居然自己就想明白了。

## 适用场景

- 数学问题
- 编程算法
- 逻辑推理

不适合：
- 创意写作
- 简单问答

贵，但值。
