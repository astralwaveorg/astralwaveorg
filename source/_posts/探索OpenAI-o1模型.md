# 探索 OpenAI o1 模型

2025 年 2 月，传说中的 o1 终于体验到了。

## o1 是什么

o1 是 OpenAI 的新模型系列，主打**推理能力**。

和 GPT-4 的区别：
- GPT-4：快，需要 prompt 引导思维
- o1：慢，但会自己推理

## 测试

### 数学问题

```
问：一个数组，除了一个元素外其他都出现了两次，找出那个元素

答：[1, 2, 3, 1, 2]

思路：
- 用异或运算
- 相同数字异或为 0
- 0 与任何数异或等于该数
- 所以最终结果就是出现一次的数

代码：
def find_single(arr):
    result = 0
    for num in arr:
        result ^= num
    return result
```

居然自己就想明白了！

### 编程问题

```
写一个快速排序

思考：
1. 选择基准元素
2. 分区：小于基准放左边，大于放右边
3. 递归排序左右两部分

代码实现正确，注释清晰。
```

### 逻辑推理

```
三位老师中，谁教数学？
- 张老师教语文
- 李老师教数学
- 王老师教英语
- 张老师和李老师是邻居

答：李老师教数学（因为张老师教语文，王老师教英语）
```

## 适用场景

### 适合

- 数学问题
- 编程算法
- 逻辑推理
- 复杂分析
- 科学研究

### 不适合

- 创意写作（太理性）
- 简单问答（浪费）
- 需要快速响应

## 缺点

### 1. 贵

o1 比 GPT-4 贵 3 倍。

### 2. 慢

思考时间从几秒到几十秒不等。

### 3. 不支持系统提示词

目前 o1 不支持 system prompt。

## 总结

o1 是另一个维度的模型。

不是替代 GPT-4，而是互补。

适合需要深度思考的问题，普通问题还是 GPT-4 更快更便宜。

贵，但值。
