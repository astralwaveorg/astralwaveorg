# Python 列表操作小结

学了一阵子 Python，感觉列表是最常用的东西了。随便记一下，防止忘记。

## 常用操作

```python
# 创建
nums = [1, 2, 3, 4, 5]

# 追加
nums.append(6)

# 切片
print(nums[1:3])  # [2, 3]

# 遍历
for n in nums:
    print(n)
```
