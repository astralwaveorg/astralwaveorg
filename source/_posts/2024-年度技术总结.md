# 2024 年度技术总结

又一年过去了。

每年这个时候都会感慨：时间过得真快。

## 技术栈变化

### 前端

从 Vue 全面转向 React + Next.js。

- React 18 的并发特性
- Next.js 14 的 App Router
- Server Components
- Tailwind CSS

### 后端

- Python 依然是主力
- 开始用 Go 写微服务
- FastAPI 越来越香

### AI

这是变化最大的一年。

- 从会用 AI 到能调教 AI
- 深入研究 Agent 系统
- 私有化部署大模型
- RAG 知识库落地

### 运维

- Docker 依然香
- K8s 还在学
- CI/CD 更完善

## 项目总结

### 1. RAG 知识库

给公司搭的 AI 问答系统。

从 0 到 1：
- 文档处理流水线
- 向量检索优化
- LLM Prompt 调优
- 前端对话界面

效果：从 60% 准确率提升到 85%。

### 2. Agent 平台

自研的 AI Agent 系统。

功能：
- 多模型支持
- 工具编排
- 记忆系统
- 反思机制

目前帮我：写代码、查资料、自动部署。

### 3. 小程序

公司内部工具小程序。

- 用户认证
- 数据看板
- 消息推送

## 技术深度

### 分布式系统

从理论到实践：

- 服务拆分
- 通信协议
- 分布式事务
- 熔断限流

### AI 工程

- Prompt Engineering
- RAG 架构
- Agent 设计
- 模型部署

## 技术之外

### 1. 输出

- 博客写了 20+ 篇
- GitHub 更活跃了
- 开始在技术社群交流

### 2. 学习方式

- 实践驱动学习
- 边做边学，不纸上谈兵
- 遇到问题，解决它

### 3. 心态

- 拥抱变化
- AI 是工具，不是威胁
- 持续学习

## 感悟

### AI 不是替代，是放大器

AI 不会替代程序员，但不会用 AI 的会被替代。

今年最大的变化：把 AI 融入工作流。

### 基础很重要

追新技术的路上，别忘了基础。

- 计算机原理
- 数据结构算法
- 设计模式
- 网络协议

### 要输出

输入重要，输出更重要。

- 写博客
- 分享知识
- 教别人

## 2025 年的目标

### 1. Agent 系统

做一个真正有用的 AI Agent。

- 更智能的规划
- 更丰富的工具
- 更好的体验

### 2. AI 落地方案

帮助更多企业用上 AI。

- 私有化部署
- 知识库优化
- 场景化方案

### 3. 技术深度

- Go 深入
- K8s 生产实践
- 性能优化

---

2024 年，充实的一年。

2025 年，继续。
