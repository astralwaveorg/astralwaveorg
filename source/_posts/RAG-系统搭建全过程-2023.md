# RAG 系统搭建全过程

给公司搭了个知识库问答系统，用的 RAG。

## 架构

```
文档 → 分块 → 向量化 → 存入向量库
                            ↓
用户问题 → 向量化 → 向量检索 → 上下文 → LLM → 回答
```

## 技术栈

- **向量库**: Qdrant / Milvus / Chroma
- **分块**: LangChain TextSplitter
- **向量化**: OpenAI Embedding / 本地模型
- **框架**: LangChain / LlamaIndex

## 关键点

1. **分块大小**: 试了 256、512、1024，最后 512 效果最好
2. **检索排序**: 用 rerank 模型效果明显提升
3. **_chunk overlap**: 设为 20% 避免丢失上下文

## 效果

准确率从 60% 提升到 85%。

但幻觉问题还是存在，得继续优化 prompt。
